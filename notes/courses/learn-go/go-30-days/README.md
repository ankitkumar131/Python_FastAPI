# Go in 30 Days — A Complete Beginner-to-Advanced Course

Welcome! This repository contains a **complete, detailed, 30-day Go programming course** that takes you from zero knowledge of Go to an advanced, interview-ready, production-capable Go developer.

## Who is this for?

- Developers who already know **Java, Python, JavaScript, or C** — Go syntax knowledge is *not* assumed.
- Complete beginners who are willing to practice daily.

## How to use this course

1. **One day = one folder.** Read `README.md` inside the day's folder, type out every example yourself, then do the exercises.
2. Every day ends with **practice questions (5 Easy / 5 Medium / 5 Hard)** and selected solutions.
3. Don't skip the **mini projects** — they build toward the final production-style application.
