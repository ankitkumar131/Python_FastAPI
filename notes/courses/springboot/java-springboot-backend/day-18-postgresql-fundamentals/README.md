# 1. Concept

PostgreSQL is a relational database **with a different dialect and features**. Do not say “it works exactly like MySQL”.

## Differences that bite

| Topic | MySQL | PostgreSQL |
|---|---|---|
| String quotes | flexible | `'strings'`, `"identifiers"` |
| Auto id | AUTO_INCREMENT | `GENERATED BY DEFAULT AS IDENTITY` or SEQUENCE |
| UUID | function/plugin | `uuid` type, `gen_random_uuid()` |
| JSON | JSON | JSON + **JSONB** (indexable) |
| Boolean | TINYINT | real BOOLEAN |
| LIMIT | LIMIT | LIMIT/OFFSET (also FETCH) |
| Upsert | ON DUPLICATE KEY | `ON CONFLICT` |

## UUID

Good for public ids (hides count). Store as `uuid` type, not VARCHAR.

## JSONB

Store flexible attributes: `{"department":"ENG","level":3}` with GIN indexes. Still not a reason to skip tables for core relations.

## JDBC

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/app_db
spring.datasource.username=app
spring.datasource.password=secret
```

Docker:

```bash
docker run --name course-postgres -e POSTGRES_USER=app -e POSTGRES_PASSWORD=secret -e POSTGRES_DB=app_db -p 5432:5432 -d postgres:16
```
